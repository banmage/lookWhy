## 1. 规划定位与核心原则

### 1.1 从“产品族规划”到“能力生态规划”

本规划文档与传统的“电机选型方案”或“产品目录规划”有本质区别。

传统电机产品规划的思维是：

```
应用市场需求分析
    ↓
寻找覆盖最广的电机型号组合
    ↓
定义产品规格书
    ↓
推向市场
```

这是**电机厂的思维**——以产品为中心，以销售为目标。

PPM Rotary Motion Module规划的思维是：

```
工业旋转动力能力空间定义
    ↓
标准接口体系设计（机械/电气/控制/性能）
    ↓
制造窗口定义（什么能力能被高效、一致地制造）
    ↓
能力族规格设计（能力空间 × 制造窗口 = 标准单元）
    ↓
规格推理模型（需求 → 约束 → 能力匹配）
    ↓
验证体系与认证模型
    ↓
制造生态构建
```

这是**标准制定者与生态构建者的思维**——以能力单元为中心，以生态协同为目标。

两者最本质的区别在于：

> **传统规划回答的是“我们做什么产品”；PPM规划回答的是“我们建立什么样的能力单元标准，让全球制造力量围绕它高效协同”。**

因此，本规划文档的名称不是《BLDC产品族规划》，而是 **《能力单元与制造生态规划》** ——这一定位本身就是对PPM战略的校准。

### 1.2 核心设计原则

基于leleby_PPM战略白皮书 v2.3和综合评审意见，本规划遵循以下核心原则：

**原则一：能力边界优先于技术路线**

PPM Rotary Motion Module定义的是“电能→可控旋转机械能”这一能力单元的标准，而非某一种电机的技术标准。内转子BLDC、外转子BLDC、PMSM、轴向磁通电机等不同技术路线，只要符合相同的接口标准和能力边界，均可纳入体系。

**原则二：制造窗口决定规格族边界**

规格族的边界不由应用需求单方面决定，而由“同一套核心制造设备能否高效生产”决定。如果一个规格族内的功率跨度导致制造商需要更换绕线机、磁钢装配线或动平衡设备，那么这个族的定义就是失败的。

**原则三：接口标准是核心资产**

PPM的真正壁垒不是某个规格的电机参数，而是**机械接口+电气接口+控制接口+性能接口**构成的完整标准体系。任何符合这些接口的旋转动力单元，无论内部技术路线如何，均可进入PPM生态。

**原则四：最少能力族覆盖最大应用空间**

在满足制造窗口约束的前提下，用最少的标准化能力单元覆盖最大的工业应用空间。这一原则的目标不是“少”本身，而是通过集约化实现供应链规模效应和制造能力聚焦。

**原则五：语义可推理是AI就绪的基础**

每个能力族的参数边界必须清晰、约束关系必须明确、推理规则必须可计算，以支持AI制造智能体自动完成需求解析、能力匹配和制造商推荐。

### 1.3 市场背景与战略窗口

全球BLDC电机市场正处于快速增长期。2025年全球BLDC市场规模约201亿美元，预计2026年将增长至213亿美元，2034年有望达到339.5亿美元，年复合增长率约6%。另一数据显示，2026年全球BLDC市场规模首次突破134.3亿美元，较2025年增长18%。中国作为全球最大生产与消费市场，产值占比达37.5%。

在更广泛的永磁同步电机（PMSM）市场，2025年全球规模约288.3亿美元，预计2026年将达311.4亿美元，年复合增长率8%。

从应用端看，全球新增工业机器人中每台需3-6台精密BLDC，人形机器人单台更是需要15-40台微型无刷电机。新能源汽车、智能家居和工业自动化三大领域构成核心增长极。

这一市场格局意味着：**旋转动力模块不是一个细分市场，而是横跨家电、汽车、工业、机器人的基础性产业**，具备极高的标准化价值。而当前市场正处于技术路线收敛（BLDC逐步替代有刷电机和交流异步电机）与需求爆发（机器人、新能源、智能设备）的交汇点——这正是PPM建立标准的最佳战略窗口。

## 2. Rotary Motion Capability Ontology（旋转动力能力本体）

### 2.1 能力定义

PPM Rotary Motion Module的能力定义如下：

> **将电能转化为可控旋转机械能的标准能力单元。**

这一能力定义包含三个核心要素：

| 要素 | 说明 |
|------|------|
| **输入** | 电能（直流/交流，指定电压等级） |
| **输出** | 旋转机械能（转速、扭矩、功率） |
| **可控性** | 速度控制、转矩控制、位置控制（通过标准控制接口） |

### 2.2 能力语义模型（OWL化规格）

基于leleby Specification Ontology框架，PPM Rotary Motion Capability以OWL语义模型表达，而非工程规格表：

```
@prefix ppm: <https://ppm.leleby.io/ontology/> .
@prefix leleby: <https://leleby.io/ontology/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

ppm:RotaryMotionCapability
  a owl:Class ;
  rdfs:subClassOf leleby:FunctionalCapability ;
  leleby:hasFunction "电能→可控旋转机械能" ;
  leleby:hasInput leleby:ElectricalEnergy ;
  leleby:hasOutput leleby:MechanicalRotation .

ppm:RM42General
  a owl:Class ;
  rdfs:subClassOf ppm:RotaryMotionCapability ;
  leleby:hasPerformanceConstraint [
    a leleby:PowerConstraint ;
    leleby:minValue 50 ;
    leleby:maxValue 300 ;
    leleby:unit "W" ;
  ] ;
  leleby:hasPerformanceConstraint [
    a leleby:SpeedConstraint ;
    leleby:minValue 1000 ;
    leleby:maxValue 15000 ;
    leleby:unit "RPM" ;
  ] ;
  leleby:hasInterfaceConstraint [
    a leleby:MechanicalInterface ;
    leleby:standardRef "PPM-INT-MECH-042" ;
  ] ;
  leleby:hasManufacturingWindow [
    a leleby:StatorManufacturingWindow ;
    leleby:statorOD 42 ;
    leleby:stackLengthMin 15 ;
    leleby:stackLengthMax 40 ;
  ] ;
  leleby:compatibleWithApplication ppm:PumpApplication .
```

**语义模型的战略意义：**

| 维度 | 工程规格表 | OWL语义模型 |
|------|-----------|-------------|
| 可读性 | 人类阅读 | 人类+机器阅读 |
| 推理能力 | 无 | 支持约束推理、一致性检查 |
| 版本管理 | 文档差异对比 | 本体版本追踪 |
| 与AI的接口 | 需人工转换 | 直接可查询 |

### 2.3 能力参数空间

旋转动力能力由以下核心参数定义，构成多维参数空间：

| 参数 | 符号 | 说明 | 约束关系 |
|------|------|------|----------|
| 功率 | P | 输出机械功率（W/kW） | P = τ × ω |
| 转速 | ω / RPM | 旋转速度（rad/s 或 RPM） | 与扭矩成反比（恒功率区） |
| 扭矩 | τ | 输出扭矩（Nm） | 与转速成反比 |
| 效率 | η | 电能→机械能转换效率 | η(P, ω, T) 三维映射 |
| 噪声 | dB(A) | 声压级 | dB(A, P, ω) 三维映射 |
| 温升 | ΔT | 温升（℃） | ΔT(P, ω, 环境) |
| 寿命 | L10 | 90%可靠度寿命（小时） | L10(P, ω, T) |

**核心约束关系：**

```
P = τ × ω（功率 = 扭矩 × 角速度）

η = f(P, ω, T)（效率是功率、转速、温度的函数）

寿命模型：L10 = g(P, ω, T, 材料极限)
```

### 2.4 Capability Reasoning Model（规格推理层）

规格推理层是PPM能力本体与AI制造智能体之间的核心接口。它将自然语言需求转化为可计算的能力约束，再匹配到具体的PPM能力族。

**推理模型架构：**

```
┌─────────────────────────────────────────────────────────────┐
│                   输入：自然语言需求                          │
│        "我需要一款48V、250W、用于水泵的电机"                  │
├─────────────────────────────────────────────────────────────┤
│                    L5：需求解析层                            │
│        将自然语言解析为结构化需求参数                         │
│        { voltage: 48V, power: 250W, application: pump }     │
├─────────────────────────────────────────────────────────────┤
│                    L3：能力匹配层                            │
│        将需求参数与PPM能力族参数空间进行匹配                  │
│        power 250W ∈ RM42General [50W, 300W] ✓              │
│        voltage 48V ∈ RM42General [24V, 48V] ✓              │
│        application pump ∈ compatibleWithApplication ✓       │
├─────────────────────────────────────────────────────────────┤
│                   输出：能力推荐                              │
│        推荐能力族：RM42-General                              │
│        推荐接口：RM-Flange-42                               │
│        候选制造商：[Certified Manufacturer A, B, C]          │
└─────────────────────────────────────────────────────────────┘
```

**推理规则示例（以SWRL表达）：**

```
# 规则1：功率匹配
Capability(?c) ∧ hasPowerRange(?c, ?min, ?max) ∧ 
swrlb:greaterThan(?power, ?min) ∧ swrlb:lessThan(?power, ?max)
→ matchesPowerRequirement(?c, ?power)

# 规则2：应用兼容性
Capability(?c) ∧ compatibleWithApplication(?c, ?app) ∧ 
hasApplication(?req, ?app)
→ matchesApplicationRequirement(?c, ?req)

# 规则3：完整匹配
matchesPowerRequirement(?c, ?req) ∧ 
matchesInterfaceRequirement(?c, ?req) ∧ 
matchesApplicationRequirement(?c, ?req)
→ fullyMatches(?c, ?req)
```

**推理层的战略意义：**

1. **需求→能力自动映射**：AI可自动将用户需求转化为PPM能力约束
2. **约束一致性检查**：自动检测需求参数之间是否存在冲突
3. **能力组合推荐**：当单一能力族无法满足时，推荐组合方案
4. **制造商智能筛选**：基于能力匹配结果自动筛选认证制造商

### 2.5 能力边界与约束

**物理边界：**

- 效率理论极限：>95%（基于电磁学）
- 噪声物理下限：由空气动力学和机械振动决定
- 材料温度极限：磁钢居里温度 >150°C，绝缘等级对应耐温

**工程边界（第一阶段）：**

| 边界 | 范围 |
|------|------|
| 功率 | 5W – 15kW |
| 转速 | 1000 – 100000 RPM |
| 电压 | 12V / 24V / 48V / 310V（高压整流） |
| 防护 | IP30 / IP54 / IP65 |


## 3. Standard Interface Architecture（标准接口体系）

### 3.1 接口体系定位

PPM Rotary Motion Module的核心资产是**接口标准体系**，而非某个具体的电机参数。接口标准是PPM创造网络效应、实现技术路线兼容的关键。

> **任何符合PPM接口标准的旋转动力单元，无论内部技术路线如何，均可进入PPM生态。**

接口体系分为四层：

```
┌─────────────────────────────────────────────┐
│           性能接口（Performance）             │
│   转速-扭矩曲线、效率MAP、噪声限值、寿命模型    │
├─────────────────────────────────────────────┤
│           控制接口（Control）                │
│   通信协议、控制模式、反馈接口、驱动兼容       │
├─────────────────────────────────────────────┤
│           电气接口（Electrical）             │
│   电压等级、电流规格、引脚定义、连接器类型     │
├─────────────────────────────────────────────┤
│           机械接口（Mechanical）             │
│   法兰尺寸、轴径轴伸、安装孔位、公差等级       │
└─────────────────────────────────────────────┘
```

## 4. Manufacturing Window Definition（制造窗口定义）

### 4.1 制造窗口概念

**制造窗口（Manufacturing Window）** 是PPM标准体系中最具原创性的概念之一。

其核心思想是：

> **一个PPM能力族的规格范围，不应仅由应用需求决定，更应由“同一套核心制造设备能否高效生产”决定。**

如果同一个族内的功率跨度太大，导致制造商需要更换绕线机、磁钢装配线、动平衡设备或测试夹具，那么这个族就失去了“标准化模块”的意义——它仍然是多个产品的拼盘，而非一个可规模复用的能力单元。

### 4.2 制造窗口工程参数

基于行业制造设备能力调研，制造窗口的评估维度与工程参数如下：

| 维度 | 评估内容 | 工程参数 | 典型设备能力 |
|------|----------|----------|-------------|
| 定子绕线 | 同一绕线机能覆盖的定子外径和叠厚范围 | 定子外径、叠厚、线径 | 外径Φ20-130mm，叠厚5-80mm |
| 磁钢装配 | 同一装配线兼容的磁钢规格范围 | 磁钢尺寸变化≤30% | 同系列2-3种磁钢 |
| 动平衡 | 同一动平衡机覆盖的转子质量范围 | 质量范围≤5倍 | 标准动平衡机覆盖范围 |
| 测试夹具 | 同一夹具适配的规格范围 | 法兰和轴伸尺寸相同 | 同一接口代号 |
| 组装线 | 同一组装线生产的工艺一致性 | 工艺步骤相同，仅物料不同 | 换型时间≤15分钟 |

**绕线设备典型参数：**

- 定子外径范围：Φ20-130mm（标准机），超出需非标定制
- 铁芯叠厚范围：5-80mm（标准机），超限需定制设备
- 线径范围：0.15-1.2mm
- 绕线速度：50-800 RPM可调

### 4.4 制造窗口验证计划

制造窗口的理论定义需要通过真实制造环境验证。PPM将启动以下验证计划：

**验证目标：** 确认每个能力族内部的功率跨度确实可由同一套核心制造设备覆盖。

**验证方法：**

| 步骤 | 内容 | 参与方 |
|------|------|--------|
| 1 | 选取2-3家BLDC制造企业作为验证伙伴 | PPM + 制造企业 |
| 2 | 在同一生产线上试制族内最低和最高功率规格 | 制造企业 |
| 3 | 记录设备换型时间、良率、CPK等关键指标 | 制造企业 + PPM |
| 4 | 评估制造窗口假设是否成立 | PPM |
| 5 | 根据验证结果调整窗口边界 | PPM |

**验证判断标准：**

| 指标 | 通过标准 |
|------|----------|
| 设备换型时间 | ≤30分钟 |
| 最低功率规格良率 | ≥98% |
| 最高功率规格良率 | ≥98% |
| CPK（关键工序） | ≥1.33 |


## 5. Capability Class Specification（能力族规格）

### 5.1 能力族设计原则

基于第2-4章的分析，PPM Rotary Motion Module的能力族设计遵循以下原则：

1. **能力空间覆盖**：各能力族的参数空间合并后，覆盖≥80%的目标应用
2. **制造窗口兼容**：每个族内部的规格可由同一套核心制造设备生产（经4.4验证计划确认）
3. **接口标准统一**：所有族共享相同的机械/电气/控制接口体系
4. **语义可推理**：每个族的参数边界清晰、约束关系明确，支持AI推理（见2.4）
5. **数据包可表达**：每个族以标准数据包格式定义（见1.4）

本规划文档完成了PPM Rotary Motion Module从“产品族规划”到“能力生态规划”的战略升级，并在v1.0基础上进行了系统性深化。

**v1.0 → v1.1 核心升级：**

| 维度 | v1.0 | v1.1 |
|------|------|------|
| 能力本体 | 工程规格表 | OWL语义模型（2.2） |
| 推理层 | 未定义 | Capability Reasoning Model（2.4） |
| 机械接口 | 概念描述 | 具体尺寸参数 + 公差等级（3.2） |
| 制造窗口 | 假设参数 | 工程参数 + 验证计划（4.2-4.4） |
| RM-Standard | 单一族（50W-1kW） | 拆分为RM42-General + RM57-Industrial（5.2） |
| 数据定义 | 未定义 | PPM Capability Data Package（8） |

**核心转变：**

| 维度 | 传统产品规划 | PPM能力生态规划 |
|------|-------------|----------------|
| 起点 | 应用市场需求 | 能力空间 + 制造窗口 |
| 核心 | 产品型号 | 接口标准 + 能力族 + 数据包 |
| 边界 | 技术路线 | 接口兼容 + 制造窗口 |
| 目标 | 覆盖最多市场 | 建立可规模复用的能力单元 + AI可推理 |

**第一阶段能力族（Phase 1A）：**

```
PPM-RM-Micro（5–100W，内转子BLDC）
    ↓ 智能硬件/消费设备入口
PPM-RM42-General（50–300W，内转子BLDC）← 核心生态
    ↓ 轻工业/家电/自动化
PPM-RM57-Industrial（300W–1kW，内转子BLDC）← 核心生态
    ↓ 工业设备/移动机器人
PPM-RM-Power（1–15kW，内转子BLDC/PMSM）
    ↓ 重载工业扩展
PPM-RM-Torque（100W–3kW，外转子BLDC）← Phase 1B–2
    ↓ 移动设备/直驱
PPM-RM-Servo（与Precision Motion协同）← Phase 3
```

**核心原则：**

> **PPM Rotary Motion Module不是“一系列电机型号”，而是“一组由接口标准统一、由制造窗口约束、由语义模型描述、由数据包定义、可被AI推理的可复用旋转动力能力单元”。**

这一规划使PPM Rotary Motion Module真正区别于传统电机厂的产品目录——它不是告诉市场“我们有这些电机”，而是告诉行业 **“我们有这些标准化的能力单元，任何符合标准接口和制造窗口的旋转动力方案都可以进入这个生态”** 。

这正是leleby_PPM战略白皮书 v2.3所定义的：

> **“PPM是leleby工业语义基础设施在功能部件标准化领域的系统性验证平台。”**

本规划文档是该定义在Rotary Motion Module上的首次完整落地，为后续的标准规范制定提供了完整的框架基础。


*本规划文档为PPM Rotary Motion Module的技术-战略执行文件，聚焦于能力定义、接口标准、制造窗口、认证模型、数据包和实施路径，是leleby_PPM战略白皮书 v2.3的配套技术文档。*
