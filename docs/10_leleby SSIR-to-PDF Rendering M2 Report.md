# leleby SSIR 到传统 PDF 渲染 M2 初始报告

## 状态

已完成 SSIR JSON 到可审阅传统 PDF 的最小闭环。该阶段不修改 SSIR Schema、不改变 CSM 回环语义，也不把 PDF 视觉差异混入 M1 等价比较。

## 能力

- 使用 `reportlab` 生成 A4 PDF；
- 嵌入项目配置指定的中文 TrueType Collection 字体；
- 渲染文件标题、前言/引言/范围等前置要素、章节、条款、附录和正文；
- 渲染列表、表格、表头重复、公式原文、图像资产和缺失图占位；
- 写入标准号页眉和页码页脚；
- 生成独立渲染报告，记录 profile、字体、页数和缺失资产/未知内容警告；
- 生成前先执行 SSIR Schema 与引用完整性校验。

## 配置

默认配置为 `rules/rendering/gb-t-1-1-2020.yaml`。配置独立描述纸张、版心、字体、正文/标题/表格样式、页眉页脚和缺失资产策略。字体路径是环境相关配置，不应被视为跨机器固定事实。

## 当前验收

已对以下 SSIR 生成 PDF：

- `GBT 1.1-2020.ssir.json`：28 页；
- `GBT 20001.10-2014.ssir.json`：18 页。

两份 PDF 均成功生成并嵌入 WenQuanYi Zen Hei 字体；项目原有 16 项测试全部通过。

## 限制

- 当前不是 GB/T 1.1 全部印刷细则的法律合规证明；
- 封面、目次页码自动更新、复杂跨页表、精确字体替换、复杂公式排版、PDF/A 和视觉 Golden 比较尚未完成；
- `.ttc` 字体路径应在部署环境中通过渲染配置替换；
- 图像资产必须能从 SSIR 的 `assetRef` 相对 PDF 输出目录解析，否则生成文字占位并在报告中告警；
- 渲染报告页数通过 PDF 页对象计数得到，后续可接入 PDF 解析器做更严格的语义验收。
