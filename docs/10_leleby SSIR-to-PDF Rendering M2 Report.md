# leleby SSIR 到传统 PDF 渲染 M2 报告

## 状态

已完成 SSIR JSON 到可审阅传统 PDF 的闭环，并按 GB/T 1.1-2020 附录 E/F 补齐封面与占位符机制。该阶段不修改 SSIR Schema、不改变 CSM 回环语义，也不把 PDF 视觉差异混入 M1 等价比较。

## 能力

- 使用 `reportlab` 生成 A4 PDF；
- 嵌入项目配置指定的中文 TrueType Collection 字体（黑体=标题、宋体=正文，对应 GB/T 1.1 附录 F 的字体分工，见规则 GBT-P02/GEN-070）；
- 渲染 GB/T 1.1 封面：左上 ICS/CCS 两行、文件编号、横幅、文件名称、英文译名、一致性程度标识、底部发布/实施日期与发布机构（规则 GBT-L01~L09）；
- 封面必备信息占位符：文件编号、ICS、CCS、发布/实施日期、发布机构、名称任一缺失时以 “ICS ××”/“×× 发布” 等占位并保留版式，同时在渲染报告记录对应规则 ID（GBT-C01/GEN-090）；标准类文档一律渲染封面，不因 ICS/CCS 缺失而跳过整个封面；
- 渲染文件标题、前言/引言/范围等前置要素、章节、条款、附录和正文；
- 渲染列表、表格、表头重复、公式原文、图像资产和缺失图占位；
- 写入标准号页眉和页码页脚（GBT-P03/P04），页底锚定元素由页回调绘制（GEN-072）；
- 生成独立渲染报告，记录 profile、字体、页数和缺失资产/未知内容警告；有目次时预检与最终构建各跑一次封面故事，占位 warning 去重后再写报告；
- 生成前先执行 SSIR Schema 与引用完整性校验。

渲染器各函数均带“规则对应”注释，逐条映射到 `rules/base/GB_T_1.1-2020/requirements.yaml`（GBT-*）与 `rules/base/GB_T_1.1-2020/extraction-rules.yaml`（GEN-*），便于后续逐条核对。

## 配置

默认配置为 `config/rendering/GB_T_1.1-2020.yaml`（原 `rules/rendering/`，2026-08 迁移至 `config/rendering/`）。配置独立描述纸张、版心、字体、正文/标题/表格样式、页眉页脚和缺失资产策略。字体路径是环境相关配置，不应被视为跨机器固定事实。

## 限制

- 当前不是 GB/T 1.1 全部印刷细则的法律合规证明；
- 目次页码自动更新、复杂跨页表、精确字体替换、复杂公式排版、PDF/A 和视觉 Golden 比较尚未完成；
- `.ttc` 字体路径应在部署环境中通过渲染配置替换；
- 图像资产必须能从 SSIR 的 `assetRef` 相对 PDF 输出目录解析，否则生成文字占位并在报告中告警；
- 渲染报告页数通过 PDF 页对象计数得到，后续可接入 PDF 解析器做更严格的语义验收。
